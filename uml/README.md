# UML Diagrams

This folder contains PlantUML diagrams for the ecommerce project.

Files:

- `frontend-architecture.puml` — frontend route and page structure.
- `backend-models.puml` — core backend data model relationships.
- `checkout-sequence.puml` — checkout flow from browser to order creation.
- `admin-ban-sequence.puml` — admin user ban/unban flow.

To render these diagrams, use a PlantUML tool or VS Code PlantUML extension.
